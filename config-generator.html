❓ Як додати кастомне розширення (1440x1080), якщо його немає в списку CS2? ▼

🟢 Для комп'ютерів із відеокартами NVIDIA:

1. ПКМ по робочому столу → Панель керування NVIDIA.
2. «Зміна роздільної здатності» → кнопка «Налаштування» (Customize).
3. Постав галочку «Дозволити режими, які не підтримуються дисплеєм» → «Створити власну роздільну здатність».
4. Вкажи 1440 по горизонталі та 1080 по вертикалі і частоту Гц → збережи.

🔵 Для ноутбуків (Intel Graphics):

1. Відкрий Центр керування графікою Intel (Intel Graphics Command Center).
2. Перейди у Дисплей → біля вибору роздільної здатності натисни «+ Власна» (Custom).
3. Введи ширину, висоту та герцовку дисплея → збережи.
